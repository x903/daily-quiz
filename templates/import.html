支持的 Markdown 格式

格式一：标准格式

第1套
单选题
题目内容？
A. 选项A
B. 选项B
C. 选项C
D. 选项D
答案：B

格式二：ACP 风格

**1.** 题干内容？

- A. 选项A
- B. 选项B
- C. 选项C
- D. 选项D

**答案：C**

**解析：**
- **考点**：...

ACP 风格中每题自成一套，`**解析：**` 之后的说明文字会被自动忽略。

格式三：JSON 题库（.json）

{
  "date": "2026-11-06",
  "title": "HCIP-数通 练习题库",
  "questions": [
    {
      "type": "single",
      "question": "题干内容？",
      "options": {"A": "选项A", "B": "选项B", "C": "选项C", "D": "选项D"},
      "answer": ["B"],
      "explanation": "**考点**：..."
    }
  ]
}

支持题型 single / multiple / judge（或中文「单选题 / 多选题 / 判断题」）；答案可写 "B" 或 ["A","B"]；也可用系统「导出题目」生成的 sets 结构。
