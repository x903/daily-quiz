# 认证题库网 · 个人中心模块设计方案

> 版本：v1.0（2026-11-07）
> 范围：个人资料维护、密码修改、手机号 / 邮箱绑定、邮箱找回密码
> 原则：用户端与管理端完全隔离；敏感信息只存哈希 / 只展示脱敏值；所有校验前后端各做一遍，后端为准。

## 二、数据库变更

### 2.1 `users` 表（新增字段）

| 字段 | 类型（MySQL） | 类型（SQLite） | 说明 |
|---|---|---|---|
| `nickname` | `VARCHAR(64) NOT NULL DEFAULT ''` | `TEXT NOT NULL DEFAULT ''` | 昵称，2-20 字；空则回退用户名 |
| `gender` | `VARCHAR(8) NOT NULL DEFAULT '保密'` | `TEXT NOT NULL DEFAULT '保密'` | 男 / 女 / 保密 |
| `bio` | `VARCHAR(255) NOT NULL DEFAULT ''` | `TEXT NOT NULL DEFAULT ''` | 个人简介，≤200 字 |
| `phone` | `VARCHAR(20) NULL` | `TEXT` | 手机号，未绑定为 `NULL` |
| `phone_verified` | `TINYINT(1) NOT NULL DEFAULT 0` | `INTEGER NOT NULL DEFAULT 0` | 手机号是否已验证 |
| `email` | `VARCHAR(128) NULL` | `TEXT` | 邮箱（统一小写），未绑定为 `NULL` |
| `email_verified` | `TINYINT(1) NOT NULL DEFAULT 0` | `INTEGER NOT NULL DEFAULT 0` | 邮箱是否已验证 |
| `reset_token` | `VARCHAR(64) NOT NULL DEFAULT ''` | `TEXT NOT NULL DEFAULT ''` | 重置 Token 的 SHA-256，不存明文 |
| `reset_token_expire_at` | `VARCHAR(19) NOT NULL DEFAULT ''` | `TEXT NOT NULL DEFAULT ''` | `YYYY-MM-DD HH:MM:SS` |
| `updated_at` | `VARCHAR(19) NOT NULL DEFAULT ''` | `TEXT NOT NULL DEFAULT ''` | 资料最后更新时间 |

`password_hash` 已存在（werkzeug `pbkdf2:sha256` 加盐哈希，禁止明文）。

唯一性约束：`uk_users_phone (phone)`、`uk_users_email (email)`。未绑定统一写 `NULL`
（SQL 唯一索引允许多个 `NULL`），避免空串互相冲突。

```sql
-- MySQL：存量库升级
ALTER TABLE users
    ADD COLUMN `gender`      VARCHAR(8)   NOT NULL DEFAULT '保密' AFTER `nickname`,
    ADD COLUMN `bio`         VARCHAR(255) NOT NULL DEFAULT ''     AFTER `gender`,
    ADD COLUMN `phone`       VARCHAR(20)  NULL                     AFTER `bio`,
    ADD COLUMN `phone_verified` TINYINT(1) NOT NULL DEFAULT 0      AFTER `phone`,
    ADD COLUMN `email`       VARCHAR(128) NULL                     AFTER `phone_verified`,
    ADD COLUMN `email_verified` TINYINT(1) NOT NULL DEFAULT 0      AFTER `email`,
    ADD COLUMN `reset_token` VARCHAR(64)  NOT NULL DEFAULT ''      AFTER `email_verified`,
    ADD COLUMN `reset_token_expire_at` VARCHAR(19) NOT NULL DEFAULT '' AFTER `reset_token`,
    ADD COLUMN `updated_at`  VARCHAR(19)  NOT NULL DEFAULT ''      AFTER `created_at`;

UPDATE users SET phone = NULL WHERE phone = '';
UPDATE users SET email = NULL WHERE email = '';

ALTER TABLE users ADD UNIQUE KEY `uk_users_phone` (`phone`);
ALTER TABLE users ADD UNIQUE KEY `uk_users_email` (`email`);

-- SQLite：应用启动时由 models._migrate() 自动补列，并执行
CREATE UNIQUE INDEX IF NOT EXISTS uk_users_phone ON users(phone);
CREATE UNIQUE INDEX IF NOT EXISTS uk_users_email ON users(email);
```

> 生产执行顺序：先补列 → 清洗空串 → 建唯一索引。`models._migrate()` 已按此顺序实现且幂等。

### 2.2 `sms_codes`（短信验证码）

```sql
CREATE TABLE IF NOT EXISTS sms_codes (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER NOT NULL,
    phone       VARCHAR(20)  NOT NULL,
    purpose     VARCHAR(24)  NOT NULL DEFAULT 'bind_phone',
    code_hash   VARCHAR(64)  NOT NULL,
    expires_at  VARCHAR(19)  NOT NULL,
    attempts    INTEGER      NOT NULL DEFAULT 0,
    used        INTEGER      NOT NULL DEFAULT 0,
    created_at  VARCHAR(19)  NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
CREATE INDEX idx_sms_user ON sms_codes(user_id, purpose, created_at);
```

### 2.3 `email_tokens`（邮箱验证码 / 重置 Token）

```sql
CREATE TABLE IF NOT EXISTS email_tokens (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER NOT NULL,
    email       VARCHAR(128) NOT NULL,
    purpose     VARCHAR(24)  NOT NULL,             -- bind_email | reset_password
    code_hash   VARCHAR(64)  NOT NULL DEFAULT '',
    token_hash  VARCHAR(64)  NOT NULL DEFAULT '',  -- reset_password 用
    expires_at  VARCHAR(19)  NOT NULL,
    attempts    INTEGER      NOT NULL DEFAULT 0,
    used        INTEGER      NOT NULL DEFAULT 0,
    created_at  VARCHAR(19)  NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
CREATE INDEX idx_email_user ON email_tokens(user_id, purpose, created_at);
CREATE INDEX idx_email_target ON email_tokens(email, purpose, created_at);
```

`user_honors` / `quiz_records` 已存在，本模块直接复用：学习数据来自 `quiz_records` 聚合，
排行榜积分来自 `rankings`（日 / 周 / 月）。

## 三、接口列表

统一响应：成功 `{"ok": true, "data": {...}}`；失败 `{"ok": false, "error": "...", "code": "..."}`。
除找回密码两个接口外，其余均要求普通用户登录（`api_user_required`），管理员会话返回 401。

| # | 方法 | 路径 | 入参 | 返回 | 说明 |
|---|---|---|---|---|---|
| 1 | GET | `/api/user/profile` | — | `profile` / `security` / `stats` | 当前用户资料，手机邮箱为脱敏值 |
| 2 | PUT | `/api/user/profile` | `nickname`, `gender`, `bio` | `profile` | 昵称 2-20、性别枚举、简介 ≤200 |
| 3 | PUT | `/api/user/password` | `old_password`, `new_password`, `confirm_password` | `relogin: true` | 校验原密码 + 强度 + 新旧不同；成功后清 session |
| 4 | POST | `/api/user/bind-phone` | `phone` | `cooldown`, `debug_code?` | 发送短信验证码；唯一性 / 频率校验 |
| 5 | POST | `/api/user/verify-phone` | `phone`, `code` | `phone_masked` | 校验验证码并写入 `phone/phone_verified` |
| 6 | POST | `/api/user/bind-email` | `email` | `cooldown`, `debug_code?` | 发送邮箱验证码 |
| 7 | POST | `/api/user/verify-email` | `email`, `code` | `email_masked` | 校验验证码并写入 `email/email_verified=1` |
| 8 | POST | `/api/auth/forgot-password` | `email` | `sent`, `expires_in`, `debug_link?` | 公开；生成一次性 Token（30 分钟）并发邮件 |
| 9 | POST | `/api/auth/reset-password` | `token`, `password`, `confirm_password` | `ok` | 公开；Token 一次性，成功后立即失效 |

辅助页面路由（服务端渲染，非 JSON）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/profile` | 个人中心（未登录 302 → `/login?next=/profile`） |
| GET | `/forgot-password` | 找回密码第 1 步 |
| GET | `/reset-password?token=...` | 重置密码页（无 token 展示失败态） |
| GET | `/honors` | 旧地址，301 → `/profile` |

### 3.1 错误码约定

| HTTP | `code` | 场景 |
|---|---|---|
| 400 | `VALIDATION_ERROR` | 格式 / 长度 / 两次密码不一致 / 新旧密码相同 |
| 400 | `INVALID_CREDENTIALS` | 原密码错误 |
| 400 | `CODE_INVALID` / `CODE_EXPIRED` | 验证码错误 / 过期 |
| 400 | `TOKEN_INVALID` | 重置链接无效、过期或已使用 |
| 409 | `PHONE_TAKEN` / `EMAIL_TAKEN` | 已被其他账号绑定 |
| 409 | `EMAIL_NOT_BOUND` | 该邮箱未绑定任何账号（提示先绑定） |
| 429 | `RATE_LIMITED` | 发送过于频繁，`retry_after` 秒后重试 |
| 401 | `USER_AUTH_REQUIRED` | 未登录 / 管理员会话 |

## 四、安全设计

| 风险 | 措施 |
|---|---|
| 密码泄露 | werkzeug `pbkdf2:sha256` 加盐哈希；接口与页面均不回显密码 |
| 验证码爆破 | 6 位数字、10 分钟有效、单个验证码最多 5 次尝试、成功即作废 |
| 验证码轰炸 | 同账号 + 同用途 60 秒冷却；1 小时内最多 5 条 |
| 重置链接被猜 | `secrets.token_urlsafe(32)`；库中只存 SHA-256；30 分钟有效；一次性 |
| 重置接口刷量 | 同邮箱 60 秒冷却，15 分钟内最多 3 次 |
| 账号枚举 | 绑定类接口要求登录；找回密码按需求对「未绑定」给出明确引导 |
| 越权 | 所有写操作以 session 中的 `user_id` 为准，不接受请求体传入用户 id |
| 管理员串号 | `resolve_current_user()` 不识别管理员 session，`/api/user/*` 对管理员一律 401 |
| 明文展示 | 页面 / 接口只输出 `138****1234`、`abc***@gmail.com` 形式 |
